# Content Agent Dashboard

Project for BLOCK MIND. (@blockmindyt1) YouTube channel.

## What this is
5 AI agents running content operations:
1. Ideator — scouts content ideas
2. Hook & Script — writes hooks/scripts
3. Planner — plans daily content calendar
4. Analyst — analyses channel stats
5. DM Manager — handles DMs

Reports daily to Telegram. Dashboard shows all 5 agents live.
